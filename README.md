# Semantic Three-Layer Medical Image Encryption Framework

## Overview
This repository contains the implementation of a semantic three-layer encryption framework for secure medical image transmission. The proposed method utilizes bit-plane decomposition and hierarchical semantic grouping to provide adaptive security while ensuring lossless reconstruction of medical images.

---

## Methodology
The encryption process consists of the following stages:

1. Bit-plane decomposition of the input image  
2. Semantic grouping into three layers  
3. Independent encryption of each layer  
4. Layer recombination  
5. Global diffusion  

The decryption process reverses these steps to recover the original image without any loss of information.
